# PiPup для MajorDoMo

**pipup — тип TTS (modules/terminals/tts/pipup.addon.php)**
*Выводит сообщения MajorDoMo всплывающими окнами на Android TV и планшетах через приложение PiPup, с голосом от генераторов речи.*

Текст say(), sayTo() и ask() показывается окном поверх экрана. Окна выстраиваются в столбик, кириллица отображается корректно.
Голос генераторов (sanotts, piper_tts, RHVoice, Яндекс и других) воспроизводится в том же окне: сначала появляется текст, звук догоняет его.
Генератор для терминала выбирается полем «Имя пользователя»: метка в имени файла, например sanotts или yandex. Пустое поле — любой генератор.
Для сценариев: sendImage() (картинка файлом или ссылкой), sendVideo() (RTSP, HLS, WebRTC/go2rtc, с картинкой-заставкой), sendSound(), cancel().
Требования: форк PiPup (mhoogenbosch) 0.27+, порт 7979, PHP с curl. Оригинальный PiPup поддерживается только для текста и картинок.

**pipup_player — тип плеера (modules/app_player/addons/pipup_player.addon.php)**
*Плеер для MajorDoMo, который проигрывает аудиофайл или ссылку во всплывающем окне PiPup на Android TV.*

Работает через штатный playMedia() и модуль «Плеер».
Локальный файл из веб-корня сам превращается в адрес для устройства (LAN-IP сервера и порт из BASE_URL).
Окно показывается на время звучания файла.
Управления воспроизведением нет: стоп, пауза, громкость и статус в PiPup недоступны.
Требует дополнения pipup (использует его для отправки).
Общие ограничения: у PiPup один проигрыватель, поэтому следующий звук обрывает предыдущий.

## Как это устроено

Любая команда в итоге становится одним HTTP-запросом `POST /notify` к PiPup на телевизоре; разница лишь в том, сколько параметров вы задаёте сами.

Штатные функции и плеер удобны одной строкой, прямой вызов `$pipup->send…()` даёт доступ ко всем параметрам: заголовку, id, снимку до первого кадра, плашке «Live». Файл голоса приходит от генератора речи событием `SAY_CACHED_READY` и звучит в том же окне, что и текст.

## Подготовка

Все команды идут к терминалу MajorDoMo, у которого выбран тип TTS `pipup` и/или тип плеера `pipup_play`. На телевизоре должен работать PiPup; часть возможностей есть только в форке (mhoogenbosch, 0.28), они помечены «форк».

**Настройки терминала** (Терминалы → карточка):

| Поле | Значение | Зачем |
| --- | --- | --- |
| Имя (`NAME`) | `televizor` | Имя для `sayTo()`, `playMedia()`, `getTerminalsByName()` |
| Адрес (`HOST`) | `192.168.1.50` или `192.168.1.50:7979` | Адрес PiPup; без порта подставляется 7979 |
| Может говорить (`CANTTS`) | вкл. | Иначе `say`/`sayTo` не дойдут до терминала |
| Тип TTS (`TTS_TYPE`) | `pipup` | Текст и голос в окне |
| Тип плеера (`PLAYER_TYPE`) | `pipup_play` | `playMedia()`, `stopMedia()` |
| Имя пользователя (`PLAYER_USERNAME`) | пусто / метки генераторов / `device` | Чей голос звучит, см. ниже |
| Мин. уровень (`MIN_MSG_LEVEL`) | число или пусто | Сообщения ниже порога не показываются; пусто = `ThisComputer.minMsgLevel` |

**Поле «Имя пользователя»** выбирает, чей голос звучит в окне:

| Значение | Что звучит |
| --- | --- |
| пусто | Файл любого генератора речи (первый готовый) |
| `sanotts` | Только файлы с меткой `sanotts_…` |
| `sanotts, yandex` | Файлы любого из перечисленных |
| `device` | Синтезатор речи самого телевизора (форк); файлы генераторов игнорируются |

Метка ищется в имени файла без расширения как префикс `метка_` (sanotts, piper\_tts, rh, sapi) или суффикс `_метка` (yandex, google, ivona, tilde). Отклонённые файлы пишутся в лог `terminals` строкой `PiPup: skip …`.

**Подключение в сценарии.** Штатным функциям (`sayTo`, `playMedia`) ничего не нужно. Для методов дополнения (`sendVideo`, `sendImage` и др.) в начале сценария:

```php
include_once(DIR_MODULES . 'terminals/tts_addon.class.php');
include_once(DIR_MODULES . 'terminals/tts/pipup.addon.php');
$t = getTerminalsByName('televizor', 1);   // ищет по NAME или TITLE
if (!$t[0]) { DebMes('Терминал не найден', 'pipup'); return; }
$pipup = new pipup($t[0]);
```

Все методы возвращают `1`, если PiPup ответил 200, и `0` при ошибке; причина пишется в лог `terminals` (`PiPup: … failed (HTTP …)`).

**Эмодзи в сценариях** пишите кодом в двойных кавычках: `"\u{1F4F9} Дверь"`. Таблица сценариев в кодировке `utf8` заменяет 4-байтные символы на `?`.

## Голос и текст

Штатные функции MajorDoMo показывают окно с текстом сразу, а когда генератор речи готовит файл, то же окно перерисовывается со значком «🔊» и звуком. Окно одно, потому что id строится из ID терминала и текста: `mdm_` + md5(`ID|текст`).

| Вызов | Куда | Что показывает |
| --- | --- | --- |
| `say($текст, $уровень)` | Все терминалы с `CANTTS` | Окно «Уведомление» + голос |
| `sayTo($текст, $уровень, 'televizor')` | Один терминал | То же |
| `sayToSafe(…)` | Один терминал, в фоне | То же, сценарий не ждёт |
| `ask($вопрос, 'televizor')` | Один терминал | Окно «Вопрос» |
| `$pipup->sayDevice($текст, $заголовок, $секунд)` | Этот объект | Окно + синтезатор телевизора (форк), независимо от настроек |
| `$pipup->sendCommand($текст, $заголовок, $id, $голосУстройства, $секунд)` | Этот объект | Текстовое окно с любым заголовком, без файла генератора |

```php
sayTo('Стиральная машина закончила', 5, 'televizor');

// Голосом телевизора, свой заголовок, 20 с
$pipup->sayDevice('Дверь открыта', "\u{1F6AA} Охрана", 20);

// Только текст, свой id (повторный вызов продлит то же окно), 0 = автодлительность
$pipup->sendCommand('Окна открыты в спальне', "\u{1FA9F} Проветривание", 'airing', false, 0);
```

**Логика `say`/`sayTo`:**

1. MajorDoMo посылает событие `SAY`/`SAYTO`; модуль `terminals` вызывает `say()` дополнения, и сразу появляется текстовое окно.
2. Генератор речи готовит файл и посылает `SAY_CACHED_READY`; `terminals` вызывает `sayCached()`.
3. `sayCached()` проверяет поле «Имя пользователя»: `device` → файл не нужен; чужая метка → `skip`; иначе окно с тем же id перерисовывается со звуком по ссылке на файл.
4. Длительность окна = большее из автодлительности по тексту и «длина файла + 2 с».

### Если до телевизора ничего не доходит: приоритет модуля terminals

Модуль `terminals` подписан на `SAY`, `SAYTO`, `ASK`, `SAYREPLY` с приоритетом 0. MajorDoMo вызывает подписчиков по убыванию приоритета, и если кто-то выше ставит `$details['BREAK']` (так делает yandex\_tts с приоритетом 100), до `terminals` событие не доходит: нет ни окна, ни голоса `device`. Решение — поставить `terminals` выше генераторов.

**1. Посмотреть текущий порядок.** Подписки хранятся в таблице `settings`, записи `HOOK_EVENT_<СОБЫТИЕ>`. Сценарий (или консоль PHP в панели управления), кнопка «Выполнить»:

```php
foreach (array('SAY', 'SAYTO', 'ASK', 'SAYREPLY') as $e) {
    $rec = SQLSelectOne("SELECT VALUE FROM settings WHERE NAME = 'HOOK_EVENT_$e'");
    $subs = json_decode($rec['VALUE'], true);
    echo $e . ': ';
    foreach ((array)$subs as $module => $v) {
        echo $module . '=' . (isset($v['priority']) ? $v['priority'] : 0) . ' ';
    }
    echo '<br>';
}
```

Пример проблемного вывода: `SAYTO: terminals=0 yandex_tts=100`.

**2. Поднять приоритет** — один раз, тем же способом. `subscribeToEvent()` не меняет уже существующую подписку, поэтому сначала отписка, потом подписка заново:

```php
foreach (array('SAY', 'SAYTO', 'ASK', 'SAYREPLY') as $e) {
    unsubscribeFromEvent('terminals', $e);
    subscribeToEvent('terminals', $e, '', 200);
}
echo 'OK';
```

После этого шаг 1 должен показать `terminals=200`. Затем перезапустите циклы MajorDoMo (или весь MajorDoMo): подписки загружаются в константы `SETTINGS_HOOK_EVENT_*` при старте процесса. Веб-запросы увидят новый порядок сразу, а циклы (таймеры, сценарии по расписанию) — только после перезапуска.

**Почему это безопасно.** Меняется только порядок: `terminals` сразу показывает текст, затем генератор готовит файл как обычно и присылает `SAY_CACHED_READY`, а `BREAK` генератора по-прежнему останавливает остальные генераторы ниже. Подписку `SAY_CACHED_READY` трогать не нужно. Переустановка модуля `terminals` приоритет не сбрасывает (подписка уже есть); сбросит только удаление модуля — тогда повторите шаг 2.

**Вернуть как было:** тот же код с `subscribeToEvent('terminals', $e, '', 0);`.

Альтернатива — исправить сам генератор: в его `processSubscription()` заменить `$details['BREAK'] = true;` на `$details['ignoreVoice'] = true;`. Это правка чужого модуля, и она сотрётся при его обновлении, поэтому приоритет надёжнее.

## Звук

Звук проигрывается в окне по ссылке: телевизор сам скачивает файл (поле `sound`, форк ≥ 0.18).

```php
sendSound($soundUrl, $text = '', $title = '', $duration = 15, $volume = null, $id = '')
```

| Параметр | По умолчанию | Значение |
| --- | --- | --- |
| `$soundUrl` | — | Ссылка http(s), доступная телевизору. Для своего файла — `$pipup->fileUrl('cms/sounds/x.mp3')` |
| `$text` | `''` | Текст в окне |
| `$title` | `''` → «🔊» | Заголовок |
| `$duration` | 15 | Секунд показа окна, не меньше 3 |
| `$volume` | `null` | 0–1; `null` = громкость уведомлений телевизора |
| `$id` | новый каждый раз | С тем же id и тем же содержимым PiPup звук **не** повторяет |

```php
// Звонок с подписью, громкость 70%
$pipup->sendSound($pipup->fileUrl('cms/sounds/dingdong.mp3'), 'Кто-то у двери', "\u{1F514} Звонок", 10, 0.7);

// Проще через плеер: длительность = длина файла + 2 с
playMedia(ROOT . 'cms/sounds/dingdong.mp3', 'televizor');
```

Особенности форка:

- Плеер звука один: новый звук обрывает предыдущий.
- Голос устройства (`tts`) и звук (`sound`) в одном окне звучат одновременно.
- Звук по ссылке доигрывает до конца, даже если окно закрыто.

## Картинки

Для обычных картинок (jpg, png, gif, webp, bmp) — `sendImage`, для SVG и любых картинок, которые нужно точно вписать в квадрат, — `sendWebImage`.

```php
sendImage($image, $text = '', $title = '', $width = 480, $duration = 30)
sendWebImage($image, $text = '', $title = '', $size = 220, $duration = 0, $id = '')
```

|  | `sendImage` | `sendWebImage` |
| --- | --- | --- |
| `$image` | Ссылка http(s) или локальный путь к файлу | Ссылка http(s) или путь внутри веб-корня MajorDoMo |
| Как уходит | Ссылка — JSON `media.image`; локальный файл — сам файл (multipart) | Страница-обёртка `cms/cached/pipup_view.html?src=…` во встроенном браузере PiPup (тип `web`) |
| Размер | `$width` px по ширине | Вписана в квадрат `$size` × `$size` px |
| Длительность | 30 с | 0 = авто по длине `$text` |
| `$id` | всегда новый | свой id — продление / обновление на месте |
| SVG, анимированный SVG | нет (загрузчик PiPup его не показывает) | да |

```php
// Снимок камеры с диска — уйдёт файлом, доступ телевизора к серверу не нужен
$pipup->sendImage(ROOT . 'cms/cached/snapshot.jpg', 'Движение у ворот', "\u{1F4F7} Двор", 640, 20);

// Снимок из go2rtc по ссылке
$pipup->sendImage('http://192.168.1.10:1984/api/frame.jpeg?src=door', '', "\u{1F4F7} Дверь");

// Иконка погоды SVG, квадрат 220 px, длительность по тексту
$pipup->sendWebImage('templates/app_rambler/assets/icons/fill/all/clear-night.svg', 'Ясно, +3°', "\u{1F319} Погода");
```

У `sendImage` нет параметра `$id`: каждый вызов открывает новое окно. Если нужно обновлять картинку в одном окне, берите `sendWebImage` с `$id`.

## Видео, камеры и страницы

Один метод на три типа окна; видео и страницы передаются только ссылкой, телевизор подключается к источнику сам. Фон таких окон тёмный.

```php
sendVideo($uri, $text = '', $title = '', $type = 'video', $options = array())
```

| `$type` | Чем играет | Адреса |
| --- | --- | --- |
| `video` | ExoPlayer; RTSP всегда по TCP | `rtsp://`, `rtsps://`, HLS `.m3u8`, `.mp4`, `.webm`, DASH `.mpd` |
| `whep` (форк ≥ 0.25) | WebRTC во встроенной странице PiPup | go2rtc: `http://IP:1984/api/webrtc?src=<поток>` |
| `web` | Встроенный браузер (JS и автозапуск видео включены) | Любая страница, MJPEG, `stream.html` go2rtc, дашборд |

**`$options`** (все необязательные):

| Ключ | По умолчанию | Значение |
| --- | --- | --- |
| `width` | 640 | Ширина области, px |
| `height` | по пропорциям видео (`web` — 480, `whep` — 360) | Высота, px (форк) |
| `muted` | `true` | `false` — со звуком. На части приставок звук в окне перехватывает аудиовыход |
| `duration` | 30 | Секунд показа; `0` — пока не закроют `cancel()` |
| `poster` | — | Ссылка на снимок, показываемый до первого кадра (форк) |
| `id` | новый | Постоянный id: продление и обновление на месте (форк) |
| `liveBadge` | `false` | Плашка «Live» поверх видео с первого кадра (форк) |
| `liveBadgeColor` | янтарный | `#RRGGBB` |
| `liveBadgePosition` | внизу справа | `top_left`, `top_right`, `bottom_left`, `bottom_right` |

```php
$go2rtc = 'http://192.168.1.10:1984';

// WebRTC из go2rtc — быстрый старт, снимок до первого кадра, плашка Live
$pipup->sendVideo($go2rtc . '/api/webrtc?src=door', 'Движение · ' . date('H:i'), "\u{1F4F9} Дверь", 'whep', array(
    'width' => 640, 'height' => 360, 'duration' => 60, 'id' => 'cam_door',
    'poster' => $go2rtc . '/api/frame.jpeg?src=door',
    'liveBadge' => true, 'liveBadgePosition' => 'top_left',
));

// RTSP напрямую с камеры (лучше дополнительный поток H.264)
$pipup->sendVideo('rtsp://192.168.1.20:554/stream2', '', "\u{1F4F9} Двор", 'video', array('duration' => 45));

// Видеофайл со звуком
$pipup->sendVideo($pipup->fileUrl('cms/media/clip.mp4'), '', 'Ролик', 'video', array('muted' => false, 'duration' => 0));

// Веб-страница / дашборд / плеер go2rtc с запасным режимом MSE
$pipup->sendVideo($go2rtc . '/stream.html?src=door&mode=webrtc,mse', '', 'Камера', 'web', array('width' => 640, 'height' => 360, 'duration' => 60));
$pipup->sendVideo('http://192.168.1.5/menu.html', '', 'Меню', 'web', array('width' => 800, 'height' => 450, 'duration' => 120));
```

| Что выбрать | Когда |
| --- | --- |
| `whep` | Камеры через go2rtc в локальной сети — быстрее всего, ошибки видны в `/state` → `lastPopup.mediaError`; звук должен быть Opus |
| `video` | WebView приставки без WebRTC, файлы, HLS; звук для RTSP — AAC; ошибки только в `adb logcat` |
| `web` | Страницы, MJPEG, `stream.html` (молча переходит на MSE, если WebRTC не прошёл) |

Если в тексте окна есть текущее время, повторный вызов с тем же `id` раз в минуту будет перерисовывать окно и заново подключать поток. Для продления передавайте неизменный текст или продлевайте таймером MajorDoMo (рецепт ниже).

## Плеер pipup\_play

Плеер нужен, когда хватает одной строки без подключения дополнения: тип окна он выбирает сам по адресу. Подписи, снимка до первого кадра и плашки «Live» через него не задать.

```php
playMedia($путь_или_ссылка, 'televizor');   // показать / проиграть
stopMedia('televizor');                     // закрыть все окна PiPup на этом телевизоре
```

Второй аргумент — имя или адрес терминала. Если такого терминала нет, MajorDoMo берёт первый терминал, умеющий играть, или главный — опечатка в имени отправит медиа не туда.

Правила выбора проверяются сверху вниз, срабатывает первое подходящее:

| # | Адрес | Окно | Как отправляется | Длительность |
| --- | --- | --- | --- | --- |
| 1 | `rtsp://`, `rtsps://`, `rtmp://` | видео | `sendVideo(…, 'video')`, со звуком | 60 с |
| 2 | содержит `/api/webrtc` | WebRTC | `sendVideo(…, 'whep')`, со звуком | 60 с |
| 3 | `.mp3 .wav .ogg .oga .opus .m4a .aac .flac` | звук | `sendSound` | длина + 2 с; по ссылке 15 с |
| 4 | `.mp4 .mkv .webm .mov .avi .m3u8 .ts .mpd` | видео | `sendVideo(…, 'video')`, со звуком | длина + 2 с; по ссылке 60 с |
| 5 | `.jpg .jpeg .png .gif .webp .bmp` | картинка | `sendImage`; локальный файл — файлом | 30 с |
| 6 | `.svg` | картинка | `sendWebImage`, квадрат 300 px | 30 с |
| 7 | http(s) без расширения или `.html .htm .php .cgi .mjpg .mjpeg` | страница | `sendVideo(…, 'web')`, 640×360 | 60 с |
| 8 | всё остальное | звук | `sendSound` | 15 с |

```php
playMedia(ROOT . 'cms/sounds/dingdong.mp3', 'televizor');                        // 3: звук
playMedia(ROOT . 'cms/cached/snapshot.jpg', 'televizor');                        // 5: картинка файлом
playMedia('rtsp://192.168.1.10:8554/door', 'televizor');                         // 1: RTSP
playMedia('http://192.168.1.10:1984/api/webrtc?src=door', 'televizor');          // 2: WebRTC
playMedia('http://192.168.1.10:1984/stream.html?src=door', 'televizor');         // 7: страница
```

Уточнения:

- Локальные файлы должны лежать внутри веб-корня MajorDoMo: телевизор забирает их по `http://<LAN-IP сервера>:<порт из BASE_URL>/…`. Путь снаружи (`/etc/passwd`) или несуществующий файл отклоняются.
- Для видео, WebRTC и страниц id постоянный: `play_` + md5(ссылки). Повторный `playMedia()` того же потока продлевает окно, а не открывает новое. У звука и картинок id каждый раз новый.
- Снимок камеры без расширения (`http://камера/snapshot`) попадёт в правило 7 и откроется как страница — покажется, но через встроенный браузер.

## Окна: id, продление, закрытие

Что сделает PiPup с очередным запросом, решает id окна (форк ≥ 0.24):

| Запрос | Результат |
| --- | --- |
| Новый id | Новое окно; окна выстраиваются столбиком (`stack: vertical`) |
| Тот же id, то же содержимое | Ничего не перерисовывается, поток не переподключается, таймер перезапускается с новым `duration`; звук **не** повторяется |
| Тот же id, другой текст или адрес | Содержимое меняется в том же окне, на том же месте |
| Без id (оригинальный PiPup) | Один общий слот, новое окно вытесняет предыдущее |

Какой id ставит каждый метод:

| Метод | id |
| --- | --- |
| `say`, `sayTo`, `ask`, `sayCached`, `sayDevice` | `mdm_` + md5(ID терминала \| текст) — одна фраза = одно окно |
| `sendCommand` | `$id` или новый |
| `sendVideo`, `sendWebImage` | `$options['id']` / `$id` или новый |
| `sendSound` | `$id` или новый |
| `sendImage` | всегда новый |
| `playMedia` → видео / WebRTC / страница | `play_` + md5(ссылки) |
| `playMedia` → звук / картинка | новый |

**Закрытие:**

```php
$pipup->cancel('cam_door');                         // окно с этим id (форк)
$pipup->cancel();                                   // окно, отправленное без id
$pipup->cancelMessage('Стиральная машина закончила'); // окно сообщения say/sayTo/ask по его тексту
$pipup->cancelAll();                                // все окна (форк ≥ 0.24; оригинал — текущее)
stopMedia('televizor');                             // то же, что cancelAll, через плеер
```

Закрытие окна останавливает видео и страницу; звук по ссылке доигрывает.

**Состояние PiPup** для отладки: `curl -s http://192.168.1.50:7979/state` — там открытые окна, `lastPopup` и `lastPopup.mediaError` (ошибки `whep` и `web`).

## Длительность, цвета и ограничения

**Автодлительность по тексту** (`autoDuration`): 10 с + 1 с на каждые 15 символов, не больше 60 с. Применяется к `say`/`sayTo`/`ask`, к `sendCommand` и `sayDevice` при `$duration = 0`, к `sendWebImage` при `$duration = 0`.

| Метод | Длительность по умолчанию | Минимум |
| --- | --- | --- |
| `say`, `sayTo`, `ask`, `sendCommand`, `sayDevice` | авто по тексту | 10 с |
| `sayCached` | большее из авто и «длина файла + 2 с» | 10 с |
| `sendSound` | 15 с | 3 с |
| `sendImage` | 30 с | 1 с |
| `sendWebImage` | авто по тексту | — |
| `sendVideo` | 30 с; `0` = бессрочно, до `cancel()` | — |

**Цвета окон** заданы в дополнении и через параметры не меняются:

| Окна | Фон | Заголовок | Текст |
| --- | --- | --- | --- |
| Текст, звук, картинка | `#ffffff` | `#0066cc`, 20 | `#000000`, 14 |
| Видео, WebRTC, страница, `sendWebImage` | `#202124` | `#8ab4f8`, 20 | `#e8eaed`, 14 |

Все окна появляются в позиции 0 (верхний правый угол) и складываются столбиком.

**Совместимость с оригинальным PiPup.** Поля форка (`id`, `stack`, `tts`, `ttsLanguage`, `liveBadge*`) отправляются отдельно: если устройство отвечает 400, запрос повторяется без них. В самом медиа-блоке поля форка (`poster`, `height`, тип `whep`, поле `sound`) оригинал не поймёт.

| Возможность | Оригинал | Форк |
| --- | --- | --- |
| Текст, картинка, видео `video`, страница `web` | да | да |
| Несколько окон, id, продление | нет (один слот) | да (≥ 0.24) |
| Звук по ссылке, голос генератора в окне | нет | да (≥ 0.18) |
| Голос устройства (`device`, `sayDevice`) | нет | да |
| WebRTC `whep` | нет | да (≥ 0.25) |
| Снимок до первого кадра, плашка Live, `cancel?all` | нет | да |

**Технические ограничения:** таймаут соединения 2 с, запроса 4 с (файл картинки — 10 с); нужно расширение PHP `curl`; работает в PHP 7 и 8.

## Готовые рецепты

Во всех рецептах предполагается, что `$pipup` создан как в разделе «Подготовка».

**Камера по движению** — сценарий `cam_door_show`, вызывается из метода `motionDetected` датчика (`runScript('cam_door_show');`). Первое движение открывает окно без срока, каждое следующее перезапускает таймер закрытия, ничего не отправляя на телевизор.

```php
$terminalName = 'televizor';
$go2rtc   = 'http://192.168.1.10:1984';
$windowId = 'cam_door';
$timer    = 'pipup_' . $windowId;

if (timeOutExists($timer)) {
    clearTimeOut($timer);                       // окно уже открыто — только продлеваем
} else {
    include_once(DIR_MODULES . 'terminals/tts_addon.class.php');
    include_once(DIR_MODULES . 'terminals/tts/pipup.addon.php');
    $t = getTerminalsByName($terminalName, 1);
    if (!$t[0]) return;
    $pipup = new pipup($t[0]);
    $pipup->sendVideo($go2rtc . '/api/webrtc?src=door', 'Движение · ' . date('H:i'), "\u{1F4F9} Входная дверь", 'whep', array(
        'width' => 640, 'height' => 360, 'duration' => 0, 'id' => $windowId,
        'poster' => $go2rtc . '/api/frame.jpeg?src=door', 'liveBadge' => true,
    ));
}
setTimeOut($timer,
    "include_once(DIR_MODULES . 'terminals/tts_addon.class.php');" .
    "include_once(DIR_MODULES . 'terminals/tts/pipup.addon.php');" .
    "\$t = getTerminalsByName('$terminalName', 1);" .
    "if (\$t[0]) { \$p = new pipup(\$t[0]); \$p->cancel('$windowId'); }",
    60);                                        // закрыть через 60 с после последнего движения
```

**Звонок в дверь** — звук, голос и снимок одновременно (три окна встанут столбиком):

```php
$pipup->sendSound($pipup->fileUrl('cms/sounds/dingdong.mp3'), '', "\u{1F514} Звонок", 8, 0.8);
$pipup->sendImage('http://192.168.1.10:1984/api/frame.jpeg?src=door', 'Кто-то у двери', "\u{1F6AA} Дверь", 480, 30);
sayTo('Кто-то звонит в дверь', 5, 'televizor');
```

**Погода с иконкой** — текст голосом и SVG-иконка модуля app\_rambler рядом. `$text` и `$iconName` (имя иконки без расширения) собирает ваш сценарий погоды из данных модуля; id окна постоянный, поэтому повторный запуск обновит иконку в том же окне.

```php
$icon = 'templates/app_rambler/assets/icons/fill/all/' . $iconName . '.svg';
if (!is_file(ROOT . $icon)) {
    $icon = 'templates/app_rambler/assets/icons/fill/all/not-available.svg';
}
sayTo($text, 5, 'televizor');
$pipup->sendWebImage($icon, $text, "\u{1F324} Погода", 220, 0, 'weather_icon');
```

**Голос устройства для одного сообщения**, а не для всего терминала:

```php
$pipup->sayDevice('Утечка воды на кухне', "\u{1F6A8} Тревога", 60);
```
