**pipup — тип TTS (modules/terminals/tts/pipup.addon.php)**
*Выводит сообщения MajorDoMo всплывающими окнами на Android TV и планшетах через приложение PiPup, с голосом от генераторов речи.*

Текст say(), sayTo() и ask() показывается окном поверх экрана. Окна выстраиваются в столбик, кириллица отображается корректно.
Голос генераторов (sanotts, piper_tts, RHVoice, Яндекс и других) воспроизводится в том же окне: сначала появляется текст, звук догоняет его.
Генератор для терминала выбирается полем «Имя пользователя»: метка в имени файла, например sanotts или yandex. Пустое поле — любой генератор.
Для сценариев: sendImage() (картинка файлом или ссылкой), sendVideo() (RTSP, HLS, WebRTC/go2rtc, с картинкой-заставкой), sendSound(), cancel().
Требования: форк PiPup (mhoogenbosch) 0.27+, порт 7979, PHP с curl. Оригинальный PiPup поддерживается только для текста и картинок.

**pipup_player — тип плеера (modules/app_player/addons/pipup_player.addon.php)**
*Плеер для MajorDoMo, который проигрывает аудиофайл или ссылку во всплывающем окне PiPup на Android TV.*

Работает через штатный playMedia() и модуль «Плеер».
Локальный файл из веб-корня сам превращается в адрес для устройства (LAN-IP сервера и порт из BASE_URL).
Окно показывается на время звучания файла.
Управления воспроизведением нет: стоп, пауза, громкость и статус в PiPup недоступны.
Требует дополнения pipup (использует его для отправки).
Общие ограничения: у PiPup один проигрыватель, поэтому следующий звук обрывает предыдущий.
