# PiPup для MajorDoMo

Плагин выводит сообщения MajorDoMo всплывающими окнами на Android-устройствах (ТВ, приставка, планшет, панель, телефон) через приложение PiPup. Поддерживаются текст, голос генераторов речи и синтезатор самого устройства, картинки, звук, видео, WebRTC и веб-страницы.

Версия пакета: **1.0.0**. Языки интерфейса и сообщений: **english (en), русский (ru), украинский (uk)**.

## Состав пакета

| Файл | Назначение |
| --- | --- |
| `modules/terminals/tts/pipup.addon.php` | Тип TTS `pipup`: `say()`, `ask()`, `sayCached()`, `sayDevice()`, а также методы `sendCommand()`, `sendSound()`, `sendImage()`, `sendVideo()`, `sendWebImage()`, `cancel()` |
| `modules/app_player/addons/pipup_play.addon.php` | Тип плеера `pipup_play`: `playMedia()` и `stopMedia()` для любых медиа |
| `modules/pipup/pipup.lib.php` | Общая библиотека: языки, настройки, разбор голосовых команд, интеграция с «Простыми устройствами» |
| `modules/pipup_admin/pipup_admin.class.php` | Модуль «PiPup — настройки» со страницей параметров |
| `templates/pipup_admin/pipup_admin.html` | Шаблон страницы настроек |
| `languages/pipup_*.php` | Словари en / ru / ua / uk |
| `import/scripts/pipup_intent.json` | Готовый сценарий `pipup_intent` для вызова разборщика команд |
| `dist/pipup.tgz` | Готовый архив для «Маркета дополнений» |

Модуль настроек называется `pipup_admin`, а не `pipup`: класс `pipup` уже занят TTS-дополнением, и совпадение имён привело бы к ошибке при загрузке страницы терминалов.

## Установка

Самый простой способ — загрузить `dist/pipup.tgz` через **Маркет дополнений → Загрузить додаток** (панель MajorDoMo). Архив распаковывается в корень MajorDoMo, модуль `pipup_admin` регистрируется автоматически, сценарий `pipup_intent` импортируется в раздел «Сценарии».

Ручная установка и обновление описаны в [docs/INSTALL.ru.md](docs/INSTALL.ru.md). Там же — как проверить, что все файлы встали на свои места, и как откатиться.

## Подготовка терминала

На телевизоре должно быть установлено приложение PiPup (форк [mhoogenbosch](https://github.com/mhoogenbosch/PiPup), версия 0.27+): [скачать APK](https://github.com/mhoogenbosch/PiPup/releases/latest/download/PiPup.apk). Оригинальный PiPup поддерживает только текст и картинки. На сервере нужен PHP с расширением `curl`; в `config.php` параметр `BASE_URL` должен содержать порт веб-сервера.

В карточке терминала (Терминалы → редактирование) задайте:

| Поле | Значение | Зачем |
| --- | --- | --- |
| Имя (`NAME`) | `televizor` | Имя для `sayTo()`, `playMedia()` и сценариев |
| Адрес (`HOST`) | `192.168.1.50` | Только IP или имя устройства; порт можно указать, но он игнорируется |
| Может говорить (`CANTTS`) | вкл. | Иначе `say`/`sayTo` не дойдут |
| Тип TTS (`TTS_TYPE`) | `pipup` | Текст и голос в окне |
| Может проигрывать (`CANPLAY`) | вкл. | Для `playMedia()` |
| Тип плеера (`PLAYER_TYPE`) | `pipup_play` | Воспроизведение медиа |
| Голос сообщений (`PLAYER_USERNAME`) | пусто / метка / `device` | Чей голос звучит |
| Порт PiPup (`PLAYER_PORT`) | пусто | Порт PiPup, по умолчанию 7979 |
| Мин. уровень (`MIN_MSG_LEVEL`) | число или пусто | Порог показа сообщений |

Подписи полей «Голос сообщений» и «Порт PiPup» появляются автоматически, когда выбран плеер `pipup_play`; поле «Пароль» при этом скрывается. Список голосов подставляется из кеша `cms/cached/voice`.

## Настройки модуля

Откройте **Модули → PiPup — настройки**. Доступны:

- язык текста окон и язык синтезатора устройства (en-US, ru-RU, uk-UA или произвольный код BCP-47);
- генератор речи по умолчанию (метки через запятую или `device`);
- длительности текстовых окон, звука, картинок и видео;
- раскладка и позиция окон, цвета текстовых и медиа-окон;
- терминал по умолчанию и карта камер в формате JSON;
- кнопки «Сохранить», «Создать/обновить Простое устройство», «Отправить тестовое уведомление», «Восстановить по умолчанию».

Подробности — в [docs/SETTINGS.ru.md](docs/SETTINGS.ru.md), язык и голос — в [docs/I18N.ru.md](docs/I18N.ru.md).

## Языки

Язык берётся из настройки модуля; при значении `auto` — из языка сайта MajorDoMo (`SETTINGS_SITE_LANGUAGE`). Код `ua` ядра считается украинским `uk`. Переводятся заголовки окон, описание плеера, подписи полей, пункты списка голосов и ответы голосовых команд.

Для синтезатора устройства передаётся корректный код BCP-47: `en-US`, `ru-RU`, `uk-UA`. Если в настройках указан `device` (или вызван `sayDevice()`), текст произносит синтезатор телевизора, а файлы генераторов речи игнорируются.

## Вызов из сценариев

Штатные функции ничего не требуют:

```php
sayTo('Стиральная машина закончила', 5, 'televizor');
playMedia(ROOT . 'cms/sounds/dingdong.mp3', 'televizor');
stopMedia('televizor');
```

Для собственных методов дополнения подключите класс:

```php
include_once(DIR_MODULES . 'terminals/tts_addon.class.php');
include_once(DIR_MODULES . 'terminals/tts/pipup.addon.php');
$t = getTerminalsByName('televizor', 1);
$pipup = new pipup($t[0]);
```

Основные методы:

| Метод | Что делает |
| --- | --- |
| `say($текст, $уровень)` / `ask($вопрос, $уровень)` | Окно «Уведомление» / «Вопрос» с голосом по настройкам терминала |
| `sayDevice($текст, $заголовок, $секунд)` | Окно + синтезатор устройства, независимо от настроек |
| `sendCommand($текст, $заголовок, $id, $голосУстройства, $секунд)` | Текстовое окно с произвольным заголовком |
| `sendSound($url, $текст, $заголовок, $секунд, $громкость, $id)` | Звук по ссылке (форк ≥ 0.18) |
| `sendImage($изображение, $текст, $заголовок, $ширина, $секунд)` | Картинка ссылкой или файлом |
| `sendWebImage($изображение, $текст, $заголовок, $размер, $секунд, $id)` | SVG и картинки во встроенном браузере PiPup |
| `sendVideo($url, $текст, $заголовок, $тип, $options)` | `video`, `whep` (WebRTC go2rtc), `web` |
| `cancel($id)`, `cancelMessage($текст)`, `cancelAll()` | Закрыть одно окно / окно сообщения / все окна |

Все методы возвращают `1` при HTTP 200 и `0` при ошибке; причина пишется в лог `cms/debmes`, канал `terminals`.

Пример камеры через go2rtc:

```php
$pipup->sendVideo('http://192.168.1.10:1984/api/webrtc?src=door', 'Движение', 'Дверь', 'whep', array(
    'width' => 640, 'height' => 360, 'duration' => 60, 'id' => 'cam_door',
    'poster' => 'http://192.168.1.10:1984/api/frame.jpeg?src=door', 'liveBadge' => true,
));
```

## Простые устройства и голосовые команды

Кнопка в настройках модуля создаёт объект `SPipupNotifier` и «Простое устройство» типа `relay` с псевдонимами на трёх языках. Команды «включи экран PiPup» и «выключи экран PiPup» вызывают методы `turnOn` и `turnOff`. Метод `intent` разбирает фразы видов «покажи камеру door», «скажи текст», «покажи картинку», «закрой уведомление», «закрой все окна», «повтори» — на русском, английском и украинском языках.

Подробнее и с примерами — [docs/SIMPLE_DEVICES.ru.md](docs/SIMPLE_DEVICES.ru.md).

## Если сообщения не доходят

1. Проверьте, что тип TTS `pipup` выбран и включён «Может говорить».
2. Проверьте port 7979 и доступность `http://<IP-телевизора>:7979/state`.
3. Убедитесь, что модуль `terminals` имеет приоритет выше генераторов речи, которые ставят `BREAK` (например `yandex_tts`). Лечение — `unsubscribeFromEvent('terminals', $e); subscribeToEvent('terminals', $e, '', 200);` и перезапуск циклов.
4. Посмотрите лог `terminals` и включите подробный лог в настройках модуля.

Полный список проверок — [docs/TROUBLESHOOTING.ru.md](docs/TROUBLESHOOTING.ru.md).

## Совместимость

- PHP 7.0–8.2, расширение `curl`.
- MajorDoMo с модулями `terminals` и `app_player`.
- Форк PiPup (mhoogenbosch) 0.27+ — полные возможности; оригинальный PiPup — только текст и картинки. Поля форка отправляются отдельно, и при ответе 400 запрос повторяется без них (можно отключить в настройках).
- Таймаут соединения 2 с, запроса 4 с (передача файла картинки — 10 с).
