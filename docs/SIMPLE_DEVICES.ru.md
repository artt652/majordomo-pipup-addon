# Простые устройства и голосовые команды

Интеграция использует штатный модуль MajorDoMo `devices` («Простые устройства»). Плагин создаёт объект `SPipupNotifier` и строку в таблице `devices`, после чего устройство видно в интерфейсе и участвует в разборе события `COMMAND`.

## Создание устройства

1. Установите пакет, откройте **Модули → PiPup — настройки**.
2. Заполните «Терминал по умолчанию» — имя терминала из карточки (например `televizor`).
3. При желании заполните «Карта камер» JSON:

```json
{
  "default": "http://192.168.1.10:1984/api/webrtc?src=door",
  "door": "http://192.168.1.10:1984/api/webrtc?src=door",
  "yard": "rtsp://192.168.1.20:554/stream2"
}
```

4. Нажмите **«Создать/обновить Простое устройство»**.

Будут созданы:

- объект `PipupNotifier` класса `SPipupNotifier` со свойствами `TERMINAL`, `STATUS`, `status`, `LAST_INTENT`, `LAST_ERROR`;
- методы `intent`, `turnOn`, `turnOff`;
- запись в `devices` с типом `relay`, заголовком «Экран PiPup» и псевдонимами на трёх языках.

Тип `relay` выбран намеренно: ядро `devices` вызывает `turnOn`/`turnOff` именно для реле, Controller, диммеров и RGB. Повторное нажатие кнопки обновляет существующую запись, а не создаёт копию. Ядро не использует `devices::addDevice()` — в этой версии MajorDoMo он сбрасывает `LINKED_OBJECT`, поэтому запись создаётся напрямую через `SQLInsert('devices', …)`.

## Голосовые команды

«Включи экран PiPup» и «выключи экран PiPup» управляют отображением: `turnOn` показывает камеру по умолчанию (или повторяет последнюю команду, если выбрано `last`), `turnOff` закрывает все окна.

Метод `intent` разбирает произвольную фразу:

| Русский | English | Українська | Действие |
| --- | --- | --- | --- |
| покажи камеру door | show camera door | покажи камеру door | Показать поток/камеру из карты камер |
| покажи картинку | show image | покажи картинку | Показать картинку по псевдониму или ссылке |
| скажи текст | say text | скажи текст | Окно с текстом и голосом терминала |
| закрой уведомление … | close notification … | закрий повідомлення … | Закрыть окно сообщения по тексту |
| закрой все окна | close all | закрий всі вікна | Закрыть все окна PiPup |
| повтори | repeat | повтори | Повторить последнюю успешную команду |

Разбор не зависит от языка интерфейса: правила для en/ru/uk проверяются все сразу, язык фразы определяется по ключевому слову. Результат записывается в свойства `STATUS`, `LAST_INTENT`, `LAST_ERROR`.

## Вызов из сценария

Самый короткий способ — через метод объекта:

```php
callMethod('PipupNotifier.intent', array('phrase' => 'Покажи камеру door'));
```

Или через импортированный сценарий `pipup_intent`:

```php
$phrase = 'Скажи Вода закипела';
$terminal = 'televizor';
$res = runScript('pipup_intent');
```

Сценарий читает переменные `$phrase` (или `$command`) и `$terminal`, возвращает массив `array('ok', 'message', 'action', 'arg', 'lang')` и пишет сообщение в свойство `pipupLastResult`.

Прямой вызов из сценария без объекта и сценария:

```php
include_once(DIR_MODULES . 'pipup/pipup.lib.php');
$res = pipup_handle_intent('Покажи камеру door', 'televizor');
```

## Карта камер и типы окон

Значение карты камер читается функцией `pipup_camera_url($псевдоним)`. Ключ `default` используется, если псевдоним не указан. Тип окна определяется автоматически:

- ссылка содержит `/api/webrtc` → `whep` (WebRTC go2rtc, форк ≥ 0.25);
- http/https → `web` (встроенный браузер);
- RTSP или другое → `video` (ExoPlayer).

Принудительный тип задаётся настройкой «Тип окна камеры». Окно получает постоянный идентификатор `intent_` + md5(ссылки): повтор команды продлевает существующее окно, а не открывает новое.

## Ограничения

- Если терминал в настройках не найден, команда возвращает `ok = false` и сообщение `terminal not found` в `LAST_ERROR`.
- «Повтори» защищено от рекурсии: если последней была команда «повтори», возвращается «команда не распознана».
- Для оригинального PiPup команды с `tts`, `whep` и картой камер недоступны: устройство ответит 400, а плагин повторит запрос без полей форка (если включена соответствующая настройка).
