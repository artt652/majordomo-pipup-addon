# Языки: текст и голос

Поддерживаются английский (`en`), русский (`ru`) и украинский (`uk`). В ядре MajorDoMo украинский язык исторически называется `ua`, поэтому в пакете есть оба файла — `pipup_ua.php` и `pipup_uk.php` с одинаковым содержимым.

## Как выбирается язык

1. Если в настройках модуля указано `en`, `ru` или `uk`, используется это значение.
2. При `auto` берётся константа `SETTINGS_SITE_LANGUAGE`; `ua` преобразуется в `uk`, неизвестный код даёт `en`.
3. Словарь загружается из `ROOT/languages/pipup_<код>.php`. Если файла нет — из `pipup_default.php` (английский). Дополнительная копия лежит в `modules/pipup/languages/` для ручной установки только папки `modules/`.

Функция `pipup_t($ключ, $резерв)` возвращает строку по ключу. Второй аргумент — резервное значение на случай отсутствующего словаря; он же используется старыми addon-файлами без библиотеки.

## Что именно переводится

- Заголовки окон: «Уведомление», «Вопрос», «Камера» и значок 🔊.
- Описание плеера `pipup_play` на странице терминала, в том числе скрытая часть «Подробнее».
- Подписи полей «Голос сообщений», «Порт PiPup», подсказки и пункты списка голосов.
- Человекочитаемые названия генераторов речи: sanoTTS, Piper, RHVoice, Windows SAPI, Яндекс, Google, Ivona, Tilde.
- Ответы разборщика голосовых команд и название простого устройства.

Эмодзи (`🔊`, `🖼`, `▶`) не переводятся — они заданы в словарях байтовыми последовательностями и одинаковы во всех языках.

## Язык синтезатора устройства

Синтезатор Android ожидает код BCP-47, а не код сайта. Библиотека возвращает:

| Язык интерфейса | Код `ttsLanguage` |
| --- | --- |
| `en` | `en-US` |
| `ru` | `ru-RU` |
| `uk` | `uk-UA` |

Поле `ttsLanguage` отправляется только вместе с полем `tts` (методы `sayDevice()` и `sendCommand()` с `$deviceTts = true`, а также `say()`/`ask()` при выборе `device`). Если устройство не поддерживает эти поля, запрос повторяется без них по правилу HTTP 400.

В настройках можно указать произвольный код, например `en-GB`. Валидация допускает формат `xx` или `xx-YYYY` (2–3 буквы языка и до 8 символов региона); регион приводится к верхнему регистру.

## Голос генераторов речи

Метки генераторов ищутся в имени файла кеша без расширения:

- префикс: `sanotts_<md5>`, `piper_tts_<md5>`, `rh_<md5>`, `sapi_<md5>`;
- суффикс: `<md5>_yandex`, `<md5>_google`, `<md5>_ivona`, `<md5>_tilde`.

Поле «Голос сообщений» (`PLAYER_USERNAME`) может содержать несколько меток через запятую — файл подойдёт, если он создан любым из перечисленных генераторов. Значение `device` означает, что файлы генераторов не используются вообще: говорить будет синтезатор телевизора. Отклонённые файлы пишутся в лог `terminals` строкой `PiPup: skip …`.

## Добавление четвёртого языка

1. Скопируйте `languages/pipup_en.php` в `pipup_<код>.php` и переведите значения массива `$PIPUP_STRINGS`. Ключи менять нельзя.
2. Добавьте код в список на странице настроек (`pipup_admin.class.php`, массив `LANG_OPTIONS`) и в `pipup_lang()`/`pipup_tts_language()` библиотеки.
3. При необходимости добавьте отображаемое имя языка в `docs/` и `README.md`.

Словарь подключается по коду сайта автоматически: править `load_settings.php` или шаблоны ядра не нужно.
