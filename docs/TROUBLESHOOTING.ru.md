# Диагностика

## 1. Нет ни текста, ни голоса

1. В карточке терминала проверьте «Может говорить» и тип TTS `pipup`.
2. Проверьте «Мин. уровень»: сообщения ниже порога не показываются.
3. Проверьте приоритет подписок. Модуль `terminals` подписан на `SAY`, `SAYTO`, `ASK`, `SAYREPLY` с приоритетом 0. Если другой генератор (например `yandex_tts`, приоритет 100) ставит `$details['BREAK']`, событие до `terminals` не доходит. Лечение — один раз поднять приоритет:

```php
foreach (array('SAY', 'SAYTO', 'ASK', 'SAYREPLY') as $e) {
    unsubscribeFromEvent('terminals', $e);
    subscribeToEvent('terminals', $e, '', 200);
}
```

После этого перезапустите циклы MajorDoMo: подписки загружаются в константы при старте процесса. Возврат — тот же код с приоритетом 0.

## 2. Текст есть, простое устройство не реагирует

- Убедитесь, что нажата кнопка «Создать/обновить Простое устройство»: без записи в таблице `devices` ядро не разбирает название устройства в команде.
- Проверьте тип записи — должен быть `relay`. Тип `media` не вызывает `turnOn`/`turnOff` в этой версии ядра.
- Откройте объект `PipupNotifier` и посмотрите свойства `LAST_ERROR` и `LAST_INTENT`.
- Проверьте, что свойство `TERMINAL` заполнено именем существующего терминала.

## 3. Окно появляется, но нет звука

- Звук по ссылке работает только в форке PiPup ≥ 0.18. Оригинальное приложение не понимает поле `sound`.
- Проверьте, что генератор речи создал файл в `cms/cached/voice` и что метка в «Голос сообщений» совпадает с меткой файла.
- Если выбрано `device`, файлы генераторов намеренно игнорируются — говорить должен синтезатор устройства (форк PiPup).
- Проверьте `curl -s http://<IP>:7979/state`: там видно последнее окно и ошибку медиа.

## 4. Кракозябры в тексте

Отправка идёт JSON с `JSON_UNESCAPED_UNICODE` или multipart с `charset=UTF-8`. Если текст искажён:

- проверьте кодировку файла addon-а и словарей — она должна быть UTF-8 без BOM;
- для multipart-отправки картинок заголовок `Content-Type` содержит `charset=UTF-8`, а границу (`boundary`) добавляет libcurl — не собирайте multipart вручную.

## 5. Картинка не открывается

- Локальный файл должен лежать внутри веб-корня MajorDoMo. Путь снаружи (`/etc/passwd`) и несуществующий файл отклоняются.
- Телевизор должен иметь доступ к LAN-IP сервера и порту из `BASE_URL`: именно по этому адресу отдаются файлы.
- SVG показывает `sendWebImage()` через страницу-обёртку `cms/cached/pipup_view.html`; обычный `sendImage()` SVG не показывает.
- Убедитесь, что каталог `cms/cached` доступен для записи — туда пишется страница-обёртка.

## 6. Авто-язык определился неправильно

Проверьте язык сайта: при `SETTINGS_SITE_LANGUAGE = ua` используется украинский (`uk`). Если нужно принудительно задать язык — выберите `en`, `ru` или `uk` в настройках модуля. Язык кэшируется на время HTTP-запроса; после смены настройки обновите страницу.

## 7. Настройки не влияют на циклы

Конфигурация читается из `project_modules` и кэшируется в глобальных переменных на время процесса. Веб-запросы видят изменения сразу, а долгоживущие циклы — только после перезапуска. Перезапустите циклы MajorDoMo после изменения длительностей, цветов или карты камер.

## 8. Полезные команды

```bash
curl -s http://192.168.1.50:7979/state
grep -i "PiPup" cms/debmes/*.log | tail -50
php -l modules/terminals/tts/pipup.addon.php
php -l modules/pipup/pipup.lib.php
```

В лог пишутся строки `PiPup: ... failed (HTTP ...)` и `PiPup: skip ...` при отфильтрованном генераторе речи. Подробный лог включается в настройках модуля.
