# Настройки модуля PiPup

Страница открывается через **Модули → PiPup — настройки**. Все значения сохраняются в `project_modules.DATA` и читаются библиотекой `modules/pipup/pipup.lib.php`. Кнопка «Восстановить по умолчанию» возвращает исходные значения.

## Язык и голос

| Настройка | По умолчанию | Что делает |
| --- | --- | --- |
| Язык текста окон | `auto` | `en`, `ru`, `uk`; при `auto` используется язык сайта MajorDoMo (`ua` считается `uk`) |
| Язык синтезатора устройства | `auto` | `en-US`, `ru-RU`, `uk-UA` или любой код BCP-47; передаётся в поле `ttsLanguage` форка PiPup |
| Генератор речи по умолчанию | пусто | Метка в имени файла кеша (`sanotts`, `piper_tts`, `rh`, `sapi`, `yandex`, `google`, `ivona`, `tilde`) или `device`. Несколько меток — через запятую |

Настройка терминала «Голос сообщений» (`PLAYER_USERNAME`) имеет приоритет над генератором по умолчанию. Если это поле пусто, используется значение модуля.

## Длительность окон

| Настройка | По умолчанию | Где применяется |
| --- | --- | --- |
| Текст: база, с | 10 | `say`, `ask`, `sayDevice`, `sendCommand`, `sendWebImage` |
| Текст: секунд на N символов | 15 | Автодлительность: база + 1 с на каждые N символов |
| Текст: максимум, с | 60 | Верхняя граница автодлительности |
| Звук, с | 15 | `sendSound`, звук в плеере по ссылке |
| Картинка, с | 30 | `sendImage`, `sendWebImage`, плеер |
| Видео/поток, с | 60 | `sendVideo`, плеер для RTSP/WebRTC/страниц |

У `sayCached()` длительность — большее из автодлительности и «длина аудиофайла + 2 с». У плеера, если длина локального файла известна, окно живёт «длина файла + 2 с».

## Окна

| Настройка | По умолчанию | Значения |
| --- | --- | --- |
| Раскладка | `vertical` | `vertical` (столбик), `horizontal`, `none` |
| Позиция | 0 | Число 0–20, передаётся как `position` |
| Повтор без полей форка | да | При HTTP 400 запрос повторяется без `id`, `stack`, `tts` — совместимость с оригинальным PiPup |
| Подробный лог | нет | Пишет все отправки в канал `terminals` |

Отключение повтора без полей форка имеет смысл только если устройства точно работают с форком: оригинальный PiPup ответит 400 и окно не появится.

## Цвета

Цвет задаётся шестнадцатеричным кодом `#RRGGBB`. Неверное значение заменяется на значение по умолчанию, а на странице появляется сообщение об ошибке.

| Группа | Заголовок | Текст | Фон |
| --- | --- | --- | --- |
| Текстовые окна | `#0066cc` | `#000000` | `#ffffff` |
| Медиа-окна (видео, WebRTC, страницы, SVG) | `#8ab4f8` | `#e8eaed` | `#202124` |

## Простое устройство и интенты

| Настройка | По умолчанию | Назначение |
| --- | --- | --- |
| Терминал по умолчанию | пусто | Имя терминала для сценариев и голосовых команд, если оно не передано явно |
| Простое устройство | `PipupNotifier` | Имя создаваемого объекта; только латинские буквы, цифры и подчёркивание |
| Карта камер (JSON) | пусто | `{"default": "http://.../api/webrtc?src=door", "door": "http://..."}` |
| Тип окна камеры | `auto` | `auto`, `whep`, `video`, `web` |
| Действие «включить» | `camera` | `camera` — показать камеру по умолчанию; `last` — повторить последнюю команду |

Карта камер используется командами «покажи камеру <псевдоним>». Ключ `default` нужен для команды без псевдонима и для «включить экран». Значение `auto` выбирает `whep` для ссылок go2rtc `/api/webrtc`, `web` для остальных http-ссылок и `video` для RTSP.

## Кнопки

- **Сохранить настройки** — запись конфигурации и сброс кэшей внутри запроса.
- **Создать/обновить «Простое устройство»** — создаёт объект `SPipupNotifier`, его методы и строку в таблице `devices`; повтор безопасен.
- **Отправить тестовое уведомление** — отправляет `sendCommand()` на терминал по умолчанию.
- **Восстановить по умолчанию** — сброс всех значений.
