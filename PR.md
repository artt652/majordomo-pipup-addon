# Пулл-реквест: Package, i18n, Settings UI, Intents и исправления

Здравствуйте! Собрал в один PR доработки плагина. Все коммиты и этот текст — на русском, разбиты по шагам, чтобы их было удобно принимать по очереди. Ничего не удаляется из старого API: два исходных addon-файла продолжают работать и отдельно от нового модуля.

## Зачем

1. Плагин был набором двух PHP-файлов без упаковки — теперь это полноценный пакет для «Маркета дополнений».
2. Тексты и голос были только русскими — добавлены английский и украинский.
3. Интерфейс настройки сводился к переименованию полей скриптом — добавлен отдельный модуль с настройками.
4. Методы работали, но не все сценарии были связаны — добавлены разбор голосовых команд и «Простое устройство».
5. Исправлены найденные ошибки и неточности в документации.

## Проверки для ревьюера

1. **Синтаксис.** На всех PHP-файлах: `php -l`. Проверено на PHP 8.2, после распаковки архива — 15 файлов без ошибок.
2. **Совместимость со старой установкой.** Убедитесь, что при копировании только `pipup.addon.php` и `pipup_play.addon.php` (без модуля) ошибок нет: срабатывают запасные функции в блоках bootstrap.
3. **Язык.** В настройках выберите `ru`, `uk`, `en` и отправьте тестовое уведомление: заголовок окна и описание плеера должны меняться. При `device` в логах/запросе должен уйти `ttsLanguage = ru-RU` / `uk-UA` / `en-US`.
4. **Настройки.** Сохраните нестандартную длительность и цвет, перезагрузите страницу — значения должны остаться. Некорректный цвет или JSON карты камер должен показать ошибку, а не сломать страницу.
5. **Медиа.** Проверьте `playMedia()` для mp3, картинки, RTSP и go2rtc WebRTC — типы окон определяются как раньше.
6. **Простое устройство.** Нажмите «Создать/обновить» дважды: вторая запись в `devices` не должна появиться. Проверьте команды «включи экран PiPup», «покажи камеру door», «закрой все окна» на русском, английском и украинском.
7. **Новый API.** На странице настроек включите `urgency`, `showProgress`, `animation` и кнопки с `callback`: в `cms/debmes` и через локальный перехват запроса проверьте, что поля ушли в JSON. Проверьте `sendSound('default', …)` и `grid` с двумя потоками. Методы `state()`, `power('on')`, `volume(array('level' => 30))` должны вернуть успех на поддерживаемом устройстве.
8. **Пакет.** `tar -tzf dist/pipup.tgz` — пути без родительской папки; загрузка архива через Маркет должна зарегистрировать модуль и импортировать сценарий `pipup_intent`.

## Совместимость и риски

- PHP 7.0+ (использован синтаксис без typed properties и стрелочных функций), проверено на 8.2.
- Ядро MajorDoMo: модули `terminals` и `app_player`. Ни один файл ядра не изменяется.
- PiPup: форк mhoogenbosch 0.27+ — полный функционал; оригинальный — текст и картинки с откатом при HTTP 400.
- Модуль назван `pipup_admin`, потому что класс `pipup` уже используется TTS-дополнением. Это единственное изменение в именовании.
- Приоритет подписок `terminals` не меняется автоматически — в документации описан рецепт для случаев с `BREAK` в других генераторах.
- Конфигурация кэшируется внутри процесса: после изменения настроек долгоживущие циклы нужно перезапустить.

## Откат

Удалите модуль `pipup_admin` и верните два addon-файла из предыдущей версии. Объект `SPipupNotifier` и запись в таблице `devices` при удалении модуля остаются — при необходимости их удаляют вручную. Подробнее — `docs/INSTALL.ru.md`.
